# Tab backgrounds

Four original UO-inspired backgrounds were generated with the built-in imagegen tool for this launcher. No game screenshots or extracted textures were used. Each final PNG is 1536 × 1024 with an opaque background and is bundled locally in the APK. There is no image download during app use.

| Tab | Final asset | Scene |
| --- | --- | --- |
| Realm | [`background-realm.png`](../app/src/main/assets/ui/background-realm.png) | Castle and riverside town |
| Client | [`background-client.png`](../app/src/main/assets/ui/background-client.png) | Moongate and forest journey |
| Saves | [`background-saves.png`](../app/src/main/assets/ui/background-saves.png) | Treasure vault |
| Journal | [`background-journal.png`](../app/src/main/assets/ui/background-journal.png) | Candlelit scribe's chamber |

The UI selects a scene using the active tab. Scenic panels share that tab's background; dark panel fills and gradient overlays preserve legibility. No animation runs behind gameplay.

## Final prompts

### realm

Use case: stylized-concept. Asset type: background illustration for an Android Ultima Online Memento launcher. Original UO-inspired late-1990s isometric fantasy pixel art, carefully drawn crisp 16-bit-style pixels, rich atmospheric depth, medieval Britannia-like world, restrained dark plum and blue-black shadows with muted antique gold highlights to fit the existing launcher. Landscape 1536 by 1024 composition. Quiet dark central area for readable interface panels, interesting scene visible around the edges and upper third. No text, no lettering, no logo, no UI, no border, no watermark. Opaque background. Scene/backdrop: A medieval stone castle above a sleepy walled town at twilight, tiny warm windows, distant blue mountains and a winding river, a few cypress trees and a stone bridge in the foreground. Calm, grand and inviting.
