# UO Memento 0.1.0 — initial Thor test

- In-app Memento source pull/compile, local server start, save and acknowledged shutdown.
- Folder/ZIP client imports and automatic portable .NET setup from the imported runtimeconfig.
- Embedded Wine/TazUO display with Turnip 26 + DXVK D3D11, VirGL and software choices.
- TRASC controller layers, rebinding, relative pointer, gear menu and keyboard.
- Gold UO shield icon, retro fantasy Realm / Client / Saves / Journal screens.
- Staged updates, world backup/restore, retained prior installations and support logs.

Install the APK, follow the README's first-test sequence, and export support logs after testing. This is a prerelease: an actual TazUO .NET 10 session and server/client coexistence on the Thor remain to be verified. No game assets are included.
