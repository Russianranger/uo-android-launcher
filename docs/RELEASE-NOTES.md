# UO Memento Mobile 0.2.19

The marked 0.2.18 Thor test confirmed startup recovery and smooth warm revisits, while tracing the largest first-entry freeze to 6.75 seconds inside synchronous chunk loading during a packet handler. Two outdoor Draw stalls contained the same boundary. This release adds focused attribution inside chunk loading before selecting a performance change.

Separate bounded chunk summaries identify map/coordinates and measure repeated file-length checks, height/stretching work, land/static construction, marker lookup and tile insertion. Child calls aggregate without per-tile output, and chunk summaries have independent reporting capacity. Existing frame/resource/packet/FNA/atlas/GC/CPU/Vulkan/Android observations remain. Managed diagnostics report revision 4; the unchanged native observer reports revision 2. Resource CPU queries remain disabled.

Install over the current app and retain data, imported client, caches and Wine/FEX runtime. Keep optional SDL OFF and original SDL active. Confirm login/world entry with Cold-load timing ON, perform the marked cold/warm route and interior phases, then export the complete ZIP. Turning cold timing OFF restores the existing verified client/atlas assemblies for normal play. Previous .17/.18 diagnostic outputs remain recognized for upgrade and interrupted-launch restoration.

Native Surface, changed regions, Surface geometry caching, signing/upgrade compatibility, audio, server, controller/input, 1280×720 canvas / 1098×720 world, the existing packet budget, 0.2.13 summaries and 0.2.14 atlas batching remain. The touch quick-menu return label remains **Back to Launcher Menu**.

Live file growth, map fallback and UltimaLive behavior remain unchanged; this release does not cache file lengths.
